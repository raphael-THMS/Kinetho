# Install Kinetho

1. Extract the ZIP to a temporary or downloads folder. FFmpeg is included; no separate FFmpeg installation is required.
2. Double-click `Install Kinetho.bat`. The setup window asks where to install Kinetho and whether to create a desktop shortcut; the default location is `%LOCALAPPDATA%\Programs\Kinetho`.
3. Click **Install** and wait for the progress bar to finish. The installer does not launch Kinetho automatically.
4. Start Kinetho from the desktop shortcut, if selected. Source videos can be placed in the installed folder's `Video edition\Videos_before_modifications` folder.

Kinetho includes its own application runtime and FFmpeg; Python and FFmpeg do not need to be installed separately. Use the language menu on the home page to switch between English and French. Kinetho remembers your choice.

The distributed EXE is not code-signed. Windows SmartScreen or an organization's application-control policy may warn about or block it. For unrestricted distribution, the publisher must sign it with a trusted code-signing certificate.

Use **Uninstall Kinetho** on the home page to remove the application, bundled FFmpeg, and desktop shortcut. Your point configuration, videos, extracted images, and annotations are kept in the installation folder. They are not included in the distributable ZIP.
