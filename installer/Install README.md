# Install Kinetho / Installer Kinetho

## English

1. Double-click `Install Kinetho.bat`, next to this `setup` folder. FFmpeg and the Python runtime are included; nothing else needs to be installed.
2. Choose the language, the installation folder and whether to create a desktop shortcut. The default location is `%LOCALAPPDATA%\Programs\Kinetho`. Folders under `Program Files` are not allowed because Kinetho saves its settings and data in its own folder.
3. Click **Install** and wait for the progress bar to finish. The installer does not launch Kinetho automatically.
4. Start Kinetho from the desktop shortcut, if selected. Source videos can be placed in the installed folder's `Video edition\Videos_before_modifications` folder.

Kinetho starts in the language chosen during installation; use the language menu on its home page to change it. Use **Uninstall Kinetho** on the home page to remove the application, FFmpeg and the desktop shortcut. Your point configuration, videos, extracted images and annotations are kept.

The EXE is not code-signed. Windows SmartScreen or an organization's application-control policy may warn about or block it.

## Français

1. Double-cliquez sur `Install Kinetho.bat`, à côté de ce dossier `setup`. FFmpeg et l’environnement Python sont inclus ; rien d’autre n’est à installer.
2. Choisissez la langue, le dossier d’installation et indiquez si vous voulez un raccourci sur le Bureau. L’emplacement par défaut est `%LOCALAPPDATA%\Programs\Kinetho`. Les dossiers situés dans `Program Files` sont refusés, car Kinetho enregistre ses réglages et ses données dans son propre dossier.
3. Cliquez sur **Installer** et attendez la fin de la barre de progression. Kinetho ne se lance pas automatiquement.
4. Lancez Kinetho avec le raccourci du Bureau, si vous l’avez choisi. Les vidéos source peuvent être placées dans le dossier `Video edition\Videos_before_modifications` du dossier d’installation.

Kinetho démarre dans la langue choisie pendant l’installation ; le menu de langue de sa page d’accueil permet d’en changer. Le bouton **Désinstaller Kinetho** de la page d’accueil supprime l’application, FFmpeg et le raccourci. Votre configuration des points, vos vidéos, les images extraites et les annotations sont conservées.

L’EXE n’est pas signé. Windows SmartScreen ou les règles de sécurité d’un établissement peuvent afficher un avertissement ou le bloquer.
